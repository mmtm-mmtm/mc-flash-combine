# 验证范围

此分离包保留原有游戏适配源码，未额外裁剪成只有一个能力的演示。推荐阅读和首次演示只走下面一条链路，避免把所有高级交互都当作最小示例前提。

## 建议演示顺序

1. 进入原版街道，网页显示 MC 连接成功。
2. 移动、跳跃，确认史蒂夫原生渲染、HUD 和街道镜头共同移动。
3. 用原生武器攻击一名原版敌人，观察其受击反馈与 MC 武器动作。
4. 让原版敌人攻击史蒂夫，确认 MC 生命下降。
5. 放置一个 MC 方块，观察原游戏敌人的街道运动碰撞；再挖除。
6. 重开，检查玩家、代理、镜头和声音是否清理。

## 本次分离实际检查

实际结果见 `分离检查.json`：源码完整性、5 个 Python 文件语法、本地运行目录准备、原版资源导入和 SWF 重建、960×540 视口与桥接回调、Gradle clientClasses 编译均通过。导入与编译在目录外的临时副本中完成，使用本机现有依赖缓存；未测试全新机器首次联网安装。

本次不会自动启动 Minecraft、网页服务、浏览器或控制桌面。不把原目录历史截图/测试结果复制进来当作新示例的运行证据。

## 已知边界

- 这是针对特定 SWF 版本的原型，不是任意 Flash 游戏自动接 MC 的工具。
- 原游戏敌人仍运行原 AI，MC 代理用于跨引擎战斗；两边并非共享同一个物理引擎。
- 新方块对原敌人的运动检查使用街道尺寸近似，不能据此宣称所有 VoxelShape 在 Flash 中精确同步。
- 源码包含背包、声音、流体、生物、盟友、Boss、重开等扩展，未在此分离版本逐项重测。
- 场景同步、HTTP 轮询与 PNG 合成存在延迟，网络公开部署、联合存档、多玩家和全部物品验证不在本例保证范围内。
- 开发快捷入口保留在页面中，正式发布面向玩家的版本应另行整理交互。
