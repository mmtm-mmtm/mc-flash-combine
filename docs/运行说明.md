# 资源准备与运行

当前示例面向 Windows，建议把源码和本地运行目录放在短英文路径中。源码可存放在 NAS，但 Gradle/Fabric 运行目录须使用本地磁盘。

## 依赖

- Java JDK 17，配置 `JAVA_HOME`，其值为 JDK 根目录。
- Python 3.10+，下文使用 `python`；辅助脚本只使用标准库。
- Gradle Wrapper 8.6 已附带。首次运行需要网络下载 Gradle、Minecraft、Fabric 和资源；不强制离线，也不跳过资源下载。
- JPEXS FFDec CLI；`prepare` 明确传入本机 `ffdec-cli.jar` 路径。
- Ruffle self-hosted 静态发行包。本地原工程使用的包元数据版本为 `@ruffle-rs/ruffle 0.7.1`；将完整发行包解压后传入，保留其许可证。Ruffle 获取入口：https://ruffle.rs/downloads/
- 自行准备匹配哈希的原版 SWF，见 `original/README.md`。

本目录不包含 MC 客户端 JAR、第三方缓存、原版游戏和 Ruffle 二进制。

## 1. 导入原版与 Ruffle，构建桥接 SWF

在本示例目录执行，按你的实际位置替换示例路径：

```powershell
$env:JAVA_HOME = 'C:\Tools\jdk-17'
python manage.py prepare --swf 'C:\GameAssets\dadnme.swf' --ffdec-jar 'C:\Toolsfdecfdec-cli.jar' --ruffle-dir 'C:\Toolsuffle-selfhosted'
python manage.py check --require-assets
```

该步骤复制原件到 `original/`，反编译到 `decompiled/`，生成 `patched-scripts/` 并重建 `web/bridge.swf`，提升为 SWF 8，再调整视口为 960×540。以上导入及生成目录均被 Git 忽略。原版 SWF 哈希不同会拒绝导入，防止错误版本套补丁。

## 2. 启动 MC（终端一）

```powershell
python manage.py mc --runtime 'C:\MCBridge\DadNMe'
```

复制当前源码和 Wrapper 到指定本地运行目录，创建独立的 `MC Dad n Me Bridge` 初始世界，再运行 Gradle `runClient`。默认运行位置为 `%LOCALAPPDATA%\DadNMeBridgeExample`。源码目录不写入 MC 缓存或玩家进度。已有 `level.dat` 保留，不覆盖已有世界；运行选项按示例重写。

仅准备运行目录而不启动：

```powershell
python manage.py mc --runtime 'C:\MCBridge\DadNMe' --prepare-only
```

本例沿用原版 MC 窗口行为，手动启动可能显示 MC 窗口；未附带其他游戏的隐藏窗口改动。不要启动原项目与本例的 MC 副本占用同一端口。

## 3. 启动网页（终端二）

```powershell
python manage.py web
```

手动打开 http://127.0.0.1:18125/?autostart=1 ，等 MC 世界就绪后开始。辅助脚本不会自动打开桌面浏览器；可在 Codex 内置浏览器访问同一地址。保持两个终端运行。

## 关闭

先退出 MC 的专用世界并正常退出客户端，再在网页服务终端按 Ctrl+C。网页关闭不意味着 MC 或 HTTP 服务自动退出。需要检查时，在 PowerShell 查看 `Get-NetTCPConnection -State Listen -LocalPort 18125,18126`，只处理确认属于本例的 PID，不批量结束全部 Java/Python 进程。

## 常见问题

- 18125 被占用：退出原项目网页服务或本例旧实例。
- 18126 有响应但 `ready:false`：确认专用世界已载入，并且网页玩法已启动；端口通畅并不代表双向场景连接完成。
- 首次缺少依赖：保持网络可用，勿套用原工程 `--offline -x downloadAssets` 参数。
- Java 路径/依赖下载失败：在启动终端检查 `java -version`、`JAVA_HOME` 和 Gradle 日志。
- 看不到原游戏：确认 `web/ruffle/ruffle.js`、WASM 和 `web/bridge.swf` 均已准备，不要直接用 file:// 打开 HTML。
